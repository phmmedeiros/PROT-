# Criativos Prot+

Foram criados oito roteiros autorais a partir dos ângulos catalogados em `01-dossie/anuncios/vencedores.md`. A estrutura de atenção, demonstração e CTA foi modelada; falas, cenas e textos são novos.

Nenhum roteiro usa depoimento, número de clientes, resultado individual ou promessa clínica. Quando uma peça precisar de evidência, a gravação deve receber `[PROVA REAL AQUI]` até que exista material autorizado.
